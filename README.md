<h1 align="center">ffmpeg, simplified.</h1>

**ffmpeg, simplified.** translates everyday language into accurate FFmpeg commands.

### Prerequisites

- [Node.js](https://nodejs.org/) (v20.19+)
- [Groq API key](https://console.groq.com/keys)

### Installation

1. **Clone the repository**:

   ```
   git clone https://github.com/gemaaaaaa/ffmpeg-simplified
   cd ffmpeg-simplified
   ```

2. **Install dependencies**:

   ```
   npm install
   ```

3. **Set up environment variables**:

   ```
   copy .env.example .env
   ```

4. **Run in development mode**:

   ```
   npm run dev
   ```

5. **Build for production**:

   ```
   npm run build
   npm start
   ```
